# github-repositories

Live site: <https://yuanaruru.com/github-repositories/> (English), <https://yuanaruru.com/github-repositories/zh-tw/> (Traditional Chinese)

Reference pages for the public GitHub repositories of `workingyuanyuan`, written for AI agents first and styled as a terminal for humans. Built with [Starlight](https://starlight.astro.build).

- Every page has a Markdown twin: drop the trailing slash from the page URL and append `.md`.
- Below the site address, `/llms.txt` (English), `/zh-tw/llms.txt` (Traditional Chinese) and `/index.json` list every page.
- English at the site address, Traditional Chinese under `/zh-tw/`.

```
pnpm install
pnpm verify
```

Rules for maintainers, human or agent, are in [AGENTS.md](AGENTS.md).
