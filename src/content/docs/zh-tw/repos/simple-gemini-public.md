## Simple Gemini 的功能

- 摘要網頁上選取的文字，或貼上、輸入至彈出視窗的文字。
- 使用 Chrome 內建的 Gemini Nano 進行本機處理。
- 或使用自備金鑰呼叫 Gemini API。

## 從 Chrome Web Store 安裝

開啟落地頁所連結的商店頁面，將擴充功能加到 Chrome。

## 從 ZIP 套件安裝

1. 從落地頁或本專案的 `downloads/` 資料夾下載 `simple-gemini-0.1.1.zip`。
2. 將 ZIP 解壓縮到一個資料夾。
3. 在 Chrome 開啟 `chrome://extensions/`。
4. 開啟右上角的開發人員模式。
5. 點擊左上角的載入未封裝項目。
6. 選擇解壓縮後的資料夾（內含 `manifest.json` 的那一層）。

0.1.1 版的 ZIP 套件位於：

```text
https://yuanaruru.com/simple-gemini-public/downloads/simple-gemini-0.1.1.zip
```
